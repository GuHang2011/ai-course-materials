# AI 基础课程模块索引

根据现有教案的课程主题整理，供备课和课程结构设计参考。这里仅列课程模块，不包含原教案中的教师、班级、授课地点、日期和课后记录。

| 课次 | 主题 | 备课重点 |
| --- | --- | --- |
| 01 | 人工智能的起源与发展、人工智能概述 | 概念、发展阶段、典型应用 |
| 02 | 人工智能概述、安全伦理与职业规划 | 应用边界、伦理与职业素养 |
| 03 | 机器学习基础（一） | 学习任务、数据与模型 |
| 04 | 机器学习基础（二） | 常见方法与任务实践 |
| 05 | 深度学习与神经网络（一） | 神经网络的基本概念 |
| 06 | 深度学习与神经网络（二） | 深度学习的应用与实践 |
| 07 | 计算机视觉 | 图像识别和视觉任务 |
| 08 | 生成式人工智能 | 生成模型与内容创作 |
| 09 | 自然语言处理 | 文本、语音与翻译任务 |
| 10 | 人工智能项目平台与流程 | 需求、数据、模型、测试与迭代 |
| 11 | 办公应用中的智能处理（一） | 文档处理与办公任务 |
| 12 | 办公应用中的智能处理（二） | 表格、汇报与工作流 |
| 13 | 智能财务应用 | 场景理解与结果复核 |
| 14 | 人工智能在市场营销中的应用 | 受众、内容与效果评估 |
| 15 | AIGC 艺术创作应用 | 提示词、生成、筛选与修改 |
| 16 | 人工智能综合实践 | 综合任务、过程记录与作品评价 |

实践任务宜使用虚构或去标识化的数据，作品应保留工具、资料来源和人工修订记录。
